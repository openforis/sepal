# Recipe developer notes

This directory describes individual recipes for developers: purpose, inputs and outputs, current workflow,
invariants, verification and local open issues or potential features. These are not end-user guides or
implementation histories. Distinguish existing behavior from proposals; recording an issue does not schedule it.

- [Sampling Design](sampling-design.md)
- [PyEO Alerts](pyeo-alerts.md)

Shared architecture, design proposals and the cross-recipe roadmap belong in
[`docs/design/recipes/`](../design/recipes/data-sources.md). Recipe notes link to those contracts rather than
defining competing versions of them. Recipe-specific improvements remain separate from shared migrations unless
explicitly included in their scope.
